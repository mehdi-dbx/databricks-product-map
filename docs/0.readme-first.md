## The project

`ai-tree-mindmap` is an internal Databricks field app, a Databricks App with four tabs:

- **AI Ecosystem Tree** and **Data Science Tree**: two mind maps of Databricks products. A click on a capsule opens a panel with its note, status, docs, deck and its problem/solution block (`solves`).
- **Data & AI Story**: a slide deck in the browser, "AI and Data Science on Databricks". It has an overview, 9 chapters, 47 slides and an appendix, the capability map. It is also exported as a PDF, one 16:9 page per slide.
- **Decks**: a searchable list of internal Databricks decks.

Everything is static. `app/build.py` embeds the data into one HTML file. `app/app.py` (FastAPI) serves it.

## Start a session

1. Read `CLAUDE.md`.
2. For a Story task, read `docs/feature-tree.md`, `docs/story-tools.md`, then the doc of the task: `docs/story-editorial-guide.md` for slides, `docs/story-cement.md` for chapter intros.
3. Run `python3 scripts/story_check.py` to see the current state.
4. Read the last entries of `docs/story-journal.md` for the latest decisions.

Do not read the folders listed under "History" below. They hold older and conflicting versions.

## Commands

| Task | Command |
|---|---|
| Check the Story | `python3 scripts/story_check.py` (`--diff OLD`, `--story FILE`, `--plan FILE`) |
| Build the app | `python3 app/build.py`. It runs the check first and stops on any error. |
| Build the PDF | `python3 scripts/story_pdf.py` |
| Run locally | `cd app && python3 app.py`, then open `http://localhost:8000`. Or open `ai-tree-mindmap.html` directly. |
| Deploy, only when asked | the two `databricks` commands in `CLAUDE.md` |
